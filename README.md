# Website học liệu — GitHub Pages

## Xuất bản
1. Tạo repository **Public** trên GitHub (ví dụ `hoc-lieu`).
2. Tải **nội dung bên trong thư mục `hoc-lieu-github/`** lên thư mục gốc của repository, giữ nguyên cấu trúc. File `index.html` phải ở thư mục gốc.
3. Mở **Settings → Pages → Build and deployment**, chọn **Deploy from a branch**, **main** và **/(root)** → Save.
4. Truy cập `https://TEN-TAI-KHOAN.github.io/hoc-lieu/` (thay tên tài khoản/repository thực tế).

## Thêm một bài mới
- Tạo thư mục dưới `chuyen-doi-so/phan-tich-va-su-dung-du-lieu/`, ví dụ `thuc-hanh-python/`.
- Thêm `index.html` trong thư mục đó và liên kết từ trang `chuyen-doi-so/phan-tich-va-su-dung-du-lieu/index.html`.
- Dùng chung `assets/style.css` để thống nhất giao diện.

## Ghi chú
Nội dung hướng dẫn gốc được chuyển thành HTML, không xác minh độc lập kết quả thống kê ghi trong tài liệu. Chỉ tải dữ liệu học sinh đã được ẩn danh lên các dịch vụ công khai.
